
# CSS Assignments

This repository contains my CSS and Web Development assignments completed as part of my college coursework.

## About the Project

The purpose of these assignments is to learn how CSS works with HTML to create attractive, well-structured, and responsive web pages.

## Assignments List

1. Convert an HTML-only page into a styled webpage
2. Create a styled resume page
3. Build a profile card using the CSS box model
4. Style a landing page section
5. Complete the Profile Card project
6. Create a responsive navigation menu
7. Create a centered login page
8. Build a product listing layout
9. Build a responsive dashboard layout
10. Build a photo gallery
11. Create a product grid
12. Make previous projects responsive

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- GitHub

## CSS Concepts Covered

- CSS selectors and properties
- Colors, backgrounds, and typography
- Margin, padding, and borders
- CSS box model
- Flexbox
- CSS Grid
- Hover effects and transitions
- Media queries
- Responsive web design

## How to Run the Projects

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Select any HTML file.
4. Open it in your web browser.
5. Resize the browser window to test responsive layouts.

## What I Learned

Through these assignments, I practised styling HTML pages, creating profile cards, designing forms and product layouts, and building responsive web pages using CSS Flexbox, Grid, and media queries.
